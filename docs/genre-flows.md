# Genre flows — the loops behind every genre we build

Used by the Dream Catcher and every build loop: pick the closest flow, keep its **core / session / meta loops**, decide **levels**, and check the **must-haves** before release.
Loops: **core** = seconds (the verb you repeat), **session** = one sitting, **meta** = across sittings. **Fun, not compulsion**: meta loops must reward mastery and curiosity, never punish absence (no streak loss, energy timers, loot boxes, FOMO).

Target first-session length (benchmarks 5 / 15 / 30 / 60 min): casual 5–15 · board/card 10–30 · arcade 5–20 · action/shooter 30–60 · RPG/adventure/sim 45–90+.

## How to use it for a request
1. Map the request to one primary flow (+ at most one secondary, e.g. "space trader + city builder").
2. **Levels?** Yes when the flow lives on authored escalation (puzzles, platformers, campaigns, adventure scenes, tower defense maps). No when it lives on systems/procedural variety (sandbox, sims, roguelites use *runs*, board games use *matches*).
3. Check the must-haves; anything the browser can't do goes into a compromise (see the end).

## Board, card & tabletop
| Flow | Core | Session | Meta | Levels | Must-haves |
|---|---|---|---|---|---|
| Abstract strategy (chess, checkers, go, reversi) | select → legal move → respond | one match vs AI/hotseat | rating vs AI levels, themes, puzzles | No (puzzle packs optional) | full rules + tests, AI levels in a worker, undo, hints, move list, save/resume, normal + creative modes |
| Solitaire / patience | drag card → legal stack | one deal | stats, deal variants | No | undo, hints, auto-complete, solvable seeds, tap-to-move |
| Deckbuilder / card battler | play cards → resolve → enemy intent | one run (3 acts) | unlock cards/relics by playing | Runs | readable intents, synergy tooltips, deck view, seeded runs |
| Auto-battler | buy/position units → watch fight | one run | unit pool unlocks | Runs | clear combat readout, speed control, synergies |
| Party / local multiplayer | short minigame | 3–10 minigames | none needed | No | hotseat/split-screen, 1-button rules, instant rematch |

## Casual & arcade
| Flow | Core | Session | Meta | Levels | Must-haves |
|---|---|---|---|---|---|
| Match-3 | swap → match → cascade | 3–10 levels | garden/world grows, new mechanics per 10 levels | Yes (goals) | cascades juiced, specials, no-move reshuffle, idle hint, Zen mode |
| Brick breaker | paddle → ball → bricks | a world (10 levels) | worlds, boss bricks | Yes | ball speed cap, power-ups, launch aim, no stuck loops |
| Stacker / one-tap | time the tap | one tower | best height, cosmetic skies | No | perfect-drop feedback, instant retry |
| Endless runner | dodge/jump/collect | one run | unlock routes, not stats | No (biomes) | fair telegraphs, speed ramp, 1-tap restart |
| Snake / arena arcade | steer → collect → grow | one run | modes | No | forgiving turn buffer, readable tail |
| Physics puzzle | place/launch → simulate | 5–10 puzzles | world map | Yes | deterministic sim, retry under 1 s, star ratings optional |
| Logic puzzle (sudoku, nonogram, sokoban) | deduce → place | a few puzzles | packs, difficulty | Yes | undo, pencil marks, unique solutions verified |
| Idle / incremental | invest → wait → reinvest | 5–10 min check-in | prestige | No | **careful**: no wait-walls, offline progress is a gift not a hook |
| Rhythm | hit on beat | one song | difficulty tiers | Yes (songs) | latency calibration, visual beat cues (audio via Fable pass) |

## Impossible or partial in a browser → standard compromises
| Asked for | Why | Compromise to offer |
|---|---|---|
| MMO / 100-player live matches / MOBA online | no realtime server tier | single-player with bots + shareable seeds/ghost replays; local hotseat |
| Voice/video chat | not supported | emotes/pings |
| VR-only | headsets unsupported | first-person 3D in any browser |
| Console release | browser platform | gamepad-friendly browser build |
| Movie-length cinematics | size/time | short in-engine cutscenes |
| Other studios' IP | rights | original game in the same genre |
| Real-money rewards / gambling | policy | in-game currency, leaderboards |
| Sexual content | PG-13 policy | **no compromise** — decline |
